# 壁紙の風水基準

## 採用する基準

本命星「六白金星（五行：金）」を軸に、土生金や金同士の比和も参考にしながら、五行全体の相生・相剋と陰陽の調和を評価する。基準の識別子は `rokupaku-five-elements-v1`。色名だけで吉凶を固定しない。

五行と形勢を参考に、スマートフォン壁紙へ適用するために定めた本アプリの基準である。住居の方位・間取り・飛星盤を用いた鑑定ではない。九宮構図は画面上の重心の分類であり、上を北・左を西などとは読み替えない。本命星を八宅の命卦とも混同しない。

| 対象 | 必須条件 |
| --- | --- |
| 配色 | 主色・補助色・差し色を指定し、色の組み合わせ、分量、彩度、明暗から全体の調和を評価する。赤・青・緑などを色名だけで禁止しない |
| 五行 | 各色を木・火・土・金・水に対応付ける。相剋の存在だけで凶とはせず、過度の衝突がある場合は分量・彩度や仲介色で調整する |
| 配色の評価 | AIが「吉」と評価し、具体的な色と五行の関係を踏まえた根拠を記載した案を採用する。「凶」「判断不能」や根拠の欠落は登録しない |
| 流れ | 静穏、または画面内の主要モチーフに穏やかに集まる内向きの流れ |
| 形状 | 丸み、または安定した矩形を主要な形に用いる |
| 配置 | 余白と重心を整え、鋭い先端による圧迫、傾倒・落下・崩壊、画面外へ流出する水や道を避ける |
| 表現 | 炎・破壊・枯死を主題にせず、穏やかな光と釣り合いのある明暗を用いる |

画面内へ向かう流れや安定した配置は、壁紙で吉の表現を一貫させるためのアプリ独自の構図基準である。参考とした五行・陰陽・環境の考え方は [American Feng Shui Institute の入門資料（pp.24, 31–32）](https://www.amfengshui.com/wp-content/uploads/woocommerce_uploads/2013/12/fs095.pdf)。この資料がスマートフォン壁紙の吉凶を定義しているわけではない。一律の面積比や特定の色名の禁止を、風水の普遍的な正解として扱わない。

## 生成と登録

1. 手動・APIの新規構図と再提案に、本命星と風水基準を直接渡す。過去の分析がない手動作成にも適用する。
2. この基準を過去実績・対象日の九星・画風の変化より優先し、許可された範囲でモチーフを探索する。
3. 構図JSONには次の形式の `feng_shui` を必須とする。配色の内訳・AIの評価と根拠・流れ・形状を記録する。例はベージュを主色、赤を差し色として土を介した相生を意図する場合。

```json
{
  "palette": [
    {"color": "ベージュ", "element": "土", "role": "主色"},
    {"color": "赤", "element": "火", "role": "差し色"}
  ],
  "color_judgement": "吉",
  "color_reason": "土のベージュを主色にし、赤は小さな差し色として火生土から土生金につなぐ。",
  "flow": "内向き",
  "structure": "丸み"
}
```

4. アプリは必須項目・型・五行と役割の許可値・主色の有無・色名の重複・評価が吉であること・根拠の有無・流れと形状の許可値・未知の項目を検証する。不適合な新規・再提案は保存せず、既存案の状態も変更しない。APIでの不適合は `composition_validation_failed` とし、ジョブを失敗として終了して自動再試行を止める。
5. 選択内容と基準の版は提案の既存 `calendar_context` に保存する。DBの列追加・既存データの書き換えは行わない。
6. 画像用プロンプトにも必須条件を渡す。明示的に選択した提案、承認済み提案、最新の未承認案の順で保存済みの指定を参照する。提案IDを省略して手動画像を保存・API画像を生成する場合も、既存の承認済み提案IDを保持し、次回の画像作成へ指定を引き継ぐ。指定を持たない旧構図の画像作成にも基準全体を適用し、矛盾する色・配置は生成時に修正する。
7. 五行の理由は `symbolism` に記載し、描画内容は `overview`・`composition`・`color_wu_xing` にも反映する。理由や基準名は画像に描き込まない。

基準を含む入力とプロンプトのハッシュで古い手動入力を検出する。旧形式のJSONはそのまま新規登録せず、最新のプロンプトで作り直す。基準を変更するときは識別子も更新する。過去実績の分析方法・履歴の評価は変更しない。

## 検証の範囲

アプリが機械検証するのは構造化された指定とAIの評価・根拠の存在であり、独立した風水鑑定ではない。色の五行への分類や根拠の妥当性、自由記述の意味、生成・アップロード画像のピクセルが指定どおりかを自動判定する機能はない。AIには自由記述との整合確認と修正も指示する。手動作成では、画像を確認できる場合に生成後の見直しと修正を行い、確認できなければ未確認と明記するよう指示する。既存画像の復元や画像のみのアップロードは再鑑定しない。

「吉」はこの基準に沿ったAIの創作上の評価を意味する。運気・当選確率の向上を保証しない。
